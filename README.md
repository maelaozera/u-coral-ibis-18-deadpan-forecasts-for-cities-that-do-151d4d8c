`u-coral-ibis-18-deadpan-forecasts-for-cities-that-do-151d4d8c`.

A single-line deadpan weather forecast for an invented coastal city,
delivered in the flat, confident tone of a TV meteorologist: sideways
rain, strong gusts, and the sea doing something it really should not.

`main.ts` writes the forecast line to `/output/entry.txt` — one line,
under 160 characters, UTF-8 plain text.
